Outbound Jellyfin → Soup only. Invite Google subjects here; clients exchange Soup assertions at POST /SoupAuth/Exchange.

Tailscale auth-key mint

Prefer a tailnet OAuth client with auth_keys scope bound to tag:soup-guest. On invite (when a Google sub is known), the plugin mints a single-use ephemeral key and deposits it to Soup. Credentials stay on this Jellyfin host — Soup never receives them.

Use - with OAuth access tokens (default).
